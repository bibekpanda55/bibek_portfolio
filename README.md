# bibek_portfolio

Personal portfolio of Bibek Panda, Flutter engineer.

Live at **https://bibekpanda55.github.io/bibek_portfolio/**

## What's here

- `index.html`: the page.
- `assets/data.js`: all content (case studies, fixes, monthly commit counts). Edit this to change the text.
- `assets/app.js`: the before/after bench, in-phone skeleton screens, fixes list and timeline chart.
- `assets/style.css`: styles.
- `.github/workflows/deploy.yml`: deploys to GitHub Pages on every push to `main`.

No build step: it's plain HTML, CSS and JavaScript. Open `index.html` in a browser to preview.

The before/after screens are skeleton recreations built from the layout code of real commits to the
Innopay app, not screenshots. Code excerpts are trimmed and contain no endpoints or configuration.
